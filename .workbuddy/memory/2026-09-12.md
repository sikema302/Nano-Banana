# 2026-09-12

## 创作页多张图片改为并行生成

**问题**：用户在 PIXORY 创作页设置数量=3 时，前端 UI 显示"第 2/3 张 47%"——意味着是一张一张顺序生成的，体验不好。

**根因**：`src/App.tsx` 中 `handleGenerate` 函数原本使用 `for + await` 串行循环，每张图必须等待前一张完整提交并轮询完成后才发起下一张。

**改造**：
- 替换串行 `for (await ...)` 为 `Promise.allSettled`，所有任务同时发起、独立轮询
- 引入 `successCountRef` 跟踪真实已成功张数，作为视觉进度基线
- 进度回调包装：用"已成功张数 + 1 张活跃槽位 50%"作为视觉基线，替代原串行假设的 visual 计算，进度条更平滑
- 错误处理：区分"全部失败"（throw → catch）与"部分失败"（在 try 中继续 commit 成功图片）
- 保留 `releaseSubmission()` 语义：所有任务进入主流程后立即释放提交锁
- `setNotice` 增加部分失败的轻提示（"已生成 N 张（M 张失败）"）

**验证**：`npx tsc --noEmit` 类型检查通过。

**文件**：`src/App.tsx` 行 6555-6630。
