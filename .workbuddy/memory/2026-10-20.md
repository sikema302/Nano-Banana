## 渠道统计表：Grok Image 只按 1K/2K 分组

- 现象：后台「渠道统计」里 Grok_Image 同一 provider 出现两行 `1K / default / 1:1`、`2K / default / 16:9`，分辨率列太啰嗦。
- 根因：`server/provider-metrics.ts` 的 `canonicalConfiguration()` 只对 banana / gpt-image-1~2 / gpt-image-2.5 / gpt-image-2-adobe 做了归一化，Grok 落到兜底 `return configuration` 原样保留。
- 修复：新增 grok 分支 → `imageSize === '1K' ? '1K' : '2K'`（Grok 上游本就只有 1K/2K），同一 provider 的不同比例自动合并成一行。
- 注意：老数据不用迁移——`publicRows()` 在读取时重新做 canonical 归并，历史行下次刷新即合并。
- 已补单测 `groups Grok Image by 1K and 2K ignoring ratio`；tsc 干净，210 个测试全通过。
