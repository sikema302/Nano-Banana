# 2026-11-27 工作日志

## 修复 muse-video 分辨率大小写 bug

- 现象：muse-video 生成视频报错「模型「muse-video」不支持分辨率 resolution="720P"；当前已定价的可用值：480p、720p、1080p」。
- 根因：`server/video-generation.ts` 对**所有走君临（junliai）渠道的模型**统一 `resolution.toUpperCase()`，
  把 muse-video 的 `720p` 误转成 `720P`，君临上游拒绝（君临只有 768p 档位要求大写 `768P`）。
- 修复：改为 `isJunliai && resolution === '768p' ? '768P' : resolution` —— 仅 minimax-h3-optimized 的 768p 转大写，
  muse-video 的 480p/720p/1080p 保持小写。
- 补测试：`video-generation.test.ts` 新增「muse-video 走君临 resolution 保持小写」用例。
- 验证：tsc 通过，219 个测试全过。已本地提交 b6945e4（未 push）。
