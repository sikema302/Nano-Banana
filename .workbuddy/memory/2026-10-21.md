## 性能慢/卡/图片下载慢 诊断（结论，未落地优化）

- 三根因（`/api/health` 实测）：
  1. 图片下载慢+波动 = 图片存 Cloudflare R2，访问走 `/uploads/...` → Node 302 → R2 公网域名，国内无边缘节点。
  2. 网站卡 = `eventLoopLagMs` p99 高达 1.8s（CPU 仅 9%、内存 32%），同步重活阻塞单线程：sharp 大图缩略图(limitInputPixels 1e8)、base64 编解码、SQLite 同步 flush。
  3. 打开慢 = dist JS 776KB(gzip 219KB)+CSS 175KB，Nginx 静态资源 proxy_cache off、无长缓存。
- 选定方向：先做图片加速（套国内 CDN）。**代码零改动**：R2 对象 key=`generated/<name>`、`thumbnails/<name>.webp`，且带 `Cache-Control: max-age=31536000, immutable`；只需把生产 env `R2_PUBLIC_BASE_URL` 从 R2 域名改成 CDN 加速域名后重启 Node。
- 待用户提供：R2_PUBLIC_BASE_URL 当前值、pixory.top 是否已备案、用腾讯云/阿里云 CDN。
- CDN 关键配置：源站= R2 域名、回源 HTTPS、**回源 HOST 必须设成 R2 域名**（否则 404）、CNAME 解析。
- 方案变更（用户确认没备案 + 截图）：国内 CDN 排除。R2 公网域名就是 `img.pixory.top`（Cloudflare R2 自定义域，桶名 pixory-temp-images，Proxied）。查实**源站 23.141.172.73 在香港**（NetLab Global），全部流量绕 Cloudflare 境外节点是慢主因。
