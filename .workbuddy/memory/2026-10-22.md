# 2026-10-22 工作日志

## 异地备份 SSH 免密配置（主服务器 23.141.172.73 → 雨云 154.9.24.91）

- 脚本 `scripts/offsite-backup.sh` 已 push（commit 535cd8f），随部署上主服务器。
- **关键发现：雨云 SSH 端口是 2223，不是 22，也不是 2222。**
  - 雨云 VNC 里 `ss -tlnp | grep sshd` 显示 sshd 同时监听 2222 和 2223（同一 pid）。
  - 实测（经本地代理 127.0.0.1:49766，出口 IP 58.241.51.229 大陆江苏电信）：
    - 154.9.24.91:2222 → TCP 超时（被防火墙丢包）
    - 154.9.24.91:2223 → TCP 可达（但 SSH banner 交换被 RST，疑 fail2ban 拦陌生/大陆 IP）
    - 23.141.172.73:22 / 443 → TCP 可达，但 22 的 ssh 握手 kex 阶段被 RST（与记忆一致，登不上主服务器）
- **结论：Agent 无法替用户完成免密**——进不了主服务器 shell（22 被 RST）、进不了雨云（需密码 + fail2ban）。
- 给用户的最小操作：主服务器宝塔终端执行
  `ssh-copy-id -p 2223 root@154.9.24.91`，再 `ssh -p 2223 root@154.9.24.91 "mkdir -p /www/backup/pixory && echo ok"` 验证。
- 若 2223 也从主服务器超时 → 需在雨云控制台「防火墙/安全组」放行主服务器 IP 23.141.172.73。
- 备份脚本默认端口 RAINYUN_PORT=22，落地后需改成 2223（`sed -i 's/RAINYUN_PORT="${RAINYUN_PORT:-22}"/RAINYUN_PORT="${RAINYUN_PORT:-2223}"/' ...`）。
